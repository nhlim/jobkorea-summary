# 지원자 요약 — 모바일 웹앱 (UI 샘플)

잡코리아 지원자 요약 앱의 **화면(UI) 샘플**입니다. GitHub Pages로 열리는 정적 페이지이며,
**실제 지원자 개인정보는 들어 있지 않습니다.** 화면에 보이는 이름(김OO·이OO·박OO·최OO 등),
회사명, 연봉, 경력은 모두 **가상 예시**입니다.

- 화면 상단에 `샘플 화면 · 가상 예시` 배지가 표시됩니다.
- 실제 조회는 피클 채팅에서 **“잡코리아 지원자 확인해 줘”** 라고 말씀하시면 진행됩니다.
  (하이어링센터 접속 → 이력서 열람 여부 확인 → 최신 요약 채우기, 인증번호는 그때 채팅으로)
- 조회한 내용은 저장하지 않습니다.

## 화면

| 파일 | 내용 |
|---|---|
| `index.html` | 지원자 목록(홈) + 지원자 상세 시트 + `지금 조회` 안내 모달 |
| `manifest.json` | PWA 설정 (홈 화면 추가, 테마 컬러 `#3D7BFF`) |
| `icon.svg` / `icon-192.png` / `icon-512.png` | 앱 아이콘 |
| `sw.js` | 오프라인 셸 캐시용 서비스 워커 |

## 폰에 앱처럼 추가하기 (안드로이드 크롬)

1. 아래 주소를 크롬으로 엽니다.
2. 오른쪽 위 ⋮ → **홈 화면에 추가** → **설치**.
3. 홈 화면의 `지원자 요약` 아이콘으로 전체 화면 앱처럼 열립니다.
